# 📁 Folder: public/hero

Taruh file video dan gambar untuk **Hero Section** (layar pertama yang dilihat tamu).

## File yang dibutuhkan:

| Nama File         | Format | Ukuran Maks | Keterangan                                      |
|-------------------|--------|-------------|--------------------------------------------------|
| `hero-bg.mp4`     | MP4    | ≤ 10 MB     | Video background (landscape/portrait, no audio) |
| `hero-bg.webp`    | WebP   | ≤ 500 KB    | Fallback image jika video tidak bisa diputar     |
| `hero-bg.jpg`     | JPG    | ≤ 500 KB    | Fallback tambahan (opsional)                     |

## Tips:
- Video: durasi 10–30 detik, loop, **tanpa suara**, resolusi 1080p cukup
- Gambar: foto prewedding terbaik, rasio 9:16 (portrait) untuk mobile
- Konversi ke WebP di: https://squoosh.app
- Kompres video di: https://www.freeconvert.com/video-compressor
