## Tips:
- Maksimal **6–9 foto** agar halaman tidak berat
- Rasio bebas, tapi **konsisten** (semua 1:1 atau semua 4:5)
- Konversi ke WebP di: https://squoosh.app
- Urutkan dari foto paling favorit (photo-1 = paling utama)
