# 📁 Folder: public/couple

Taruh foto untuk **Couple Section** (profil mempelai pria & wanita).

## File yang dibutuhkan:

| Nama File          | Format | Ukuran Maks | Keterangan                          |
|--------------------|--------|-------------|--------------------------------------|
| `groom.webp`       | WebP   | ≤ 300 KB    | Foto mempelai pria (close-up/formal) |
| `bride.webp`       | WebP   | ≤ 300 KB    | Foto mempelai wanita                 |
| `couple-main.webp` | WebP   | ≤ 500 KB    | Foto berdua (opsional, untuk banner) |

## Tips:
- Rasio foto: **1:1** (kotak) atau **3:4** (portrait) — lebih bagus di mobile
- Background foto: polos/blur/outdoor natural
- Konversi ke WebP di: https://squoosh.app
